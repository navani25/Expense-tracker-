## Command to create archive folder and move files (PowerShell):
```powershell
$date = Get-Date -Format "yyyy-MM-dd"
$archiveDir = "archive_$date"
New-Item -ItemType Directory -Path $archiveDir
Move-Item metadata.json $archiveDir/
Move-Item src/vite-env.d.ts $archiveDir/src/
# Note: Don't move android/app/build/ - instead add it to .gitignore
```
